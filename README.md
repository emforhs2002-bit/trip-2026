# 시드니에서 멜버른까지

2026년 10월 호주 해안 로드트립 11일 가이드. 날짜별로 한 페이지씩 넘겨 보는 정적 웹페이지이며, 한 번 열어 두면 오프라인에서도 이용할 수 있습니다.

일정표의 주요 장소를 누르면 Google Maps가 열립니다. `유명 맛집·가볼 만한 곳`의 새로고침 버튼을 누르면 현재 위치를 한 번만 확인하고, 미리 등록한 장소 중 1km 이내 후보를 가까운 순으로 표시합니다. 위치는 저장하거나 외부 서버로 전송하지 않습니다.

- `trip.js` — 일정 데이터
- `places.js` — 일정 장소의 지도 링크와 현재 위치 주변 추천 데이터
- `photos.js` — 사진 크기·크레딧 (위키미디어 공용, 각 사진의 라이선스를 따름)
- `map.js` — 해안선 (Natural Earth, 퍼블릭 도메인)
- `sw.js` — 오프라인 저장용 서비스워커 (빌드 스크립트가 생성)

글꼴: Pretendard · Hahmlet · Overpass (SIL OFL 1.1). 아이콘 일부: Lucide (ISC).
