# 시드니에서 멜버른까지

2026년 10월 호주 해안 로드트립 11일 가이드. 날짜별로 한 페이지씩 넘겨 보는 정적 웹페이지이며, 한 번 열어 두면 오프라인에서도 열린다.

- `trip.js` — 일정 데이터 (일정이 바뀌면 이 파일만 고친다)
- `photos.js` — 사진 크기·크레딧 (위키미디어 공용, 각 사진의 라이선스를 따른다)
- `map.js` — 해안선 (Natural Earth, 퍼블릭 도메인)
- `sw.js` — 오프라인 저장용 서비스워커 (빌드 스크립트가 생성)

글꼴: Pretendard · Hahmlet · Overpass (SIL OFL 1.1). 아이콘 일부: Lucide (ISC).
